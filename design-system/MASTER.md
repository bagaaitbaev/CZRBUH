# CZRBUH Design System

## Direction
Premium modern SaaS for financial operations: calm, clean, spacious, data-first.

## Tokens
- Font: IBM Plex Sans, Inter, system sans-serif
- Background: `#f6f8fb`
- Surface: `#ffffff`
- Surface soft: `#f9fbff`
- Text: `#0f172a`
- Muted text: `#64748b`
- Border: `#e2e8f0`
- Primary: `#0f172a`
- Accent: `#2563eb`
- Success: `#16a34a`
- Danger: `#dc2626`
- Radius: 10px, 14px, 18px
- Shadow: soft layered SaaS shadows only
- Spacing: 8px base grid, generous dashboard gaps

## Components
- Buttons: 44px minimum height, clear focus ring, subtle hover lift
- Cards: white surfaces, 1px border, soft shadow, no decorative gradients
- Inputs: 44px minimum height, visible focus ring, neutral borders
- Tables: sticky-looking clean headers, comfortable row height, horizontal scroll on mobile
- Navigation: dark premium sidebar on desktop, horizontal compact nav on tablet/mobile

## Avoid
- Cheap gradients, bokeh/orbs, heavy decoration
- Layout-shifting hover effects
- Low contrast muted text
- Rounded pills everywhere without hierarchy
